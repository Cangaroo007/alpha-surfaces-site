The five-minute check

Back to the top

In order. Each step tells you which link in the chain is sound, so where it stops is the answer.

1 · The queue loads

Open roadrunner.alphasurfaces.com.au/samples. Sign in at /forms first if it asks. You should see recent requests with stones against each one, and a line saying how many older ones are hidden.

2 · A request opens cleanly

Click any name. You want an address, a source line naming the person record, and a Dispatch button that is not greyed out. Greyed out means the address is incomplete — the box says which part.

3 · A real request carries the link

Submit a sample request on alphasurfaces.com.au with a disposable email, then open the new lead in Pipedrive. The note should end in a /samples/<id> link that opens the right request. Delete the test lead afterwards.

4 · Dispatch, while it is safe

With the carrier on Plain Label this produces a label and books nothing. Do it once on a known-good address and confirm the lead moves to Following up.

A page returning 200 proves nothing.

Unknown routes fall through to a catch-all that serves the homepage with a 200. Check for a phrase from the page, not a status code — and flatten the whitespace first, because the phrase may wrap across lines in the served HTML. That mistake has already cost an hour once.

Test mode, and the flip

Back to the top

STARSHIPIT_CARRIER is PlainLabel. There is no sandbox — Plain Label is the test mode. Labels print, nothing is booked, nothing is charged.

The moment it becomes MyPostBusiness

Every Dispatch buys a real label and charges the card immediately. The page starts asking for confirmation, naming the person and suburb, and the yellow test banner turns into a live one. There is no staged rollout and no per-user switch: it is on for everyone at once.

Do it in this order

Let Jess use the page in test mode until she is bored of it. Then flip, and buy one deliberate real label on an address you can verify. That order was your call and it is the right one — the expensive mistakes here are all address mistakes, and test mode finds those for free.

When Jess says it is broken

Back to the top
  • A

    “A request I know came in is not in the list”

    Three candidates, in order of likelihood. It is older than 14 days — check Show everything. It was already dispatched, so it is filtered out. Or its Enquiry reason is not Sample request, which is a CRM data problem, not a page problem.

  • B

    “The address is wrong”

    Read the source line. Person record is the normal case; anything else means the person has no delivery address and it fell back to the organisation. Fix it on the person. Expect Google's spelling when you read it back — Pipedrive geocodes after the write and replaces what was sent, which is why Queensland comes back instead of QLD.

  • C

    “It said it sent but nothing happened”

    Starshipit answers HTTP 200 with success: false. The status code is not the result; the body is. The dispatch code already checks the body — if you are reading raw logs, do the same.

  • D

    “Belinda did not get the email”

    It only fires on requests worth telling her about — someone named a stonemason company, or asked to be connected with one. The grey note on the request is the tell. The send is wrapped so it can never fail a dispatch, which also means a failure is quiet: check the logs rather than assuming it went.

What is deliberately not there

Back to the top

Three things that were considered and left out, so nobody adds them back without knowing why.

Buttons for the Pipedrive actions

Dispatching already moves the stage, and the Australia Post webhook already writes the date. A button that duplicates an automation is a way for the two to disagree, and then nobody trusts either.

A backfill of the old leads

Adding the dispatch link to ninety existing leads means ninety new notes in the CRM for no gain — they are all reachable from the queue.

And one that is not built yet: the Lead outcome field is never set when Jess closes a request, because no option id for that field is recorded anywhere. Closing sets the stage and nothing else. Worth fixing when someone is next in the field settings.

What it costs

Back to the top

Standard is B30, Parcel Post. Express is B20. Jess chooses a speed; the code is resolved server-side, so nobody has to know either of those.

Open question worth money. A flat-rate satchel (BE1PM0) is $8.57 against $9.83 for B30 — somewhere around $3,800–4,700 a year at Alpha's volume. It turns on whether the samples actually fit a satchel, which only Jess can answer. Worth asking her while she is in the page anyway.

eParcel is still open from 8 September. Alpha qualifies on volume, it removes the $126/month Starshipit fee, and it gives real lodgement confirmation, which MyPost Business cannot.

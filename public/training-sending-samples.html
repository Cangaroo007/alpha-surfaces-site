Step 1

Open the list

Go to roadrunner.alphasurfaces.com.au/samples and bookmark it. Everything waiting to be packed is there. Click a name.

Names and addresses in every clip are made up

  • Asked to sign in? Sign in at /forms first, then come back.
  • Newest at the top. The last column is how long it has been waiting.
Next — read the request →

Step 2

Read it

Three cards, in the order you need them: what to pack, where it goes, and who it is for.

  • In the box — the stones to pack.
  • Sending to — the address. Wrong? Fix it on the person in Pipedrive, then reload.
  • Who this is — if you see the grey line, Belinda is emailed automatically. Don't write to her.
Next — send it →

Step 3

Send it

Leave it on Standard and press Dispatch. The label comes back with the address already on it.

  • Right now nothing can charge anything. Test mode prints a label and books nothing. Press everything.
  • The lead moves to Following up by itself. You don't set it.
  • Samples sent fills in when Australia Post scans the parcel — not when you press the button.
Next — when to use Express →

Step 4

Express, only when asked

Standard is the answer almost every time. Pick Express when someone has actually asked for it — usually a rep who needs it on a bench tomorrow.

  • The line beside Dispatch always tells you what it is about to send as.
  • Express costs Alpha more. It is a decision, not a default.
Next — the Pipedrive box →

Step 5

The Pipedrive box

At the bottom of every request. For the things dispatching doesn't already do — each with its own button, each telling you what it did.

  • Lead stage — all five. You rarely need it; dispatching sets Following up for you.
  • Referred them to a stonemason — goes into the lead history with today's date. It does not link the company; that's still a job in Pipedrive.
  • Add a note — free text. Notes only ever get added, never replaced.
Next — when it won't send →

Step 6

When it won't send

A red box means something is missing from the address. It lists exactly what, and Dispatch stays switched off until it is fixed.

  • Fix it on the person in Pipedrive, reload the page, and the red box goes.
  • “Already sent” with a tracking number — it has gone. Nothing to do.
  • “Could not reach the server” — reload. Twice in a row, message Sean.
  • Not a real request? Use Close this request at the bottom.

Don't fall back to typing it into MyPost Business.

If the page won't send it, tell Sean rather than working around it — otherwise nobody can tell which parcels the system sent and which it didn't. And if the page and this guide disagree, the guide is wrong: send a screenshot and it gets fixed.
Next — on your phone →

Step 7

On your phone

Same address, same login. Built for the bench, not just the desk.

  • Nothing is cut off and nothing scrolls sideways.
  • The list shows the last 14 days. Around ninety older requests are hidden so they don't bury the live ones — nothing has been closed or deleted.
  • Show everything under the list brings them back if you ever need to look.

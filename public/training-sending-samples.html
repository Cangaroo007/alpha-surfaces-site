Sending samples — the new way

One page, one button

For Jess  —  16 September 2026

The short version

There is now one page that lists every sample request waiting to go out. You open a request, check the address, press Dispatch, and the label prints with the address already on it.

Three things you can stop doing

Typing addresses into MyPost Business. The address comes off the person record in Pipedrive.

Emailing Belinda when someone names their stonemason. That email now sends itself.

Setting the lead stage and filling in Samples sent. Both happen on their own.

Two things that are still yours

Packing the box. The page tells you which stones go in it — nothing can do that part for you.

Looking at the address before you send. You are the last check between a wrong address and a box arriving at a stranger's house.

Right now nothing you press here can charge anything.

The system is in test mode. Dispatch produces a label, but it does not book anything with Australia Post and does not touch the card. Press everything. Break it if you can — that is the most useful thing you can do this week.

1 · Open the list

Back to the top

Go to roadrunner.alphasurfaces.com.au/samples and bookmark it. That is the whole address — there is nothing to install.

If it asks you to sign in, sign in at roadrunner.alphasurfaces.com.au/forms first, then come back. It is the same login you already use for the forms dashboard.

Everything waiting to be packed. Who it is for, which stones they asked for, what kind of enquiry it was, and how long it has sat there — newest at the top. Click a name to open it.

The names, stones and dates in every screenshot on this page are made up. The real list will show real customers.

2 · Read the request

Back to the top

One request, top to bottom, in the order you need it.

In the box — the stones to pack. Sending to — the address, and a line saying where it was read from (“name from person, address from person”). Who this is — the kind of customer, and their stonemason if they named one. How fast — Standard unless someone has asked otherwise. Then Dispatch.

“Read from Pipedrive: the person record”

This line tells you where the address came from, so you know what to fix if it is wrong. Fix it on the person in Pipedrive, then reload this page — editing it here would only be undone the next time anything reads the record.

The grey note about Belinda

When you see it, Belinda gets an email about this request automatically the moment you dispatch it. You do not need to write to her, and you do not need to check that it sent.

3 · Standard or Express

Back to the top

Standard is the answer almost every time. It is Parcel Post, and it is what every sample has always gone as.

Choose Express only when someone has actually asked for it — usually a rep who needs it on a customer's bench tomorrow. It costs Alpha more, so it is a decision rather than a default. You never have to know a service code; the page works that out.

4 · Dispatch

Back to the top

Press it once. The label comes back, and you stick it on the box.

While the system is in test mode you get a plain label and nothing is booked. Once it goes live, pressing Dispatch buys a real label and charges the MyPost Business card — so from that day the page will ask you to confirm first, showing the name and suburb. Read that line before you confirm.

What happens on its own

The lead moves to Following up.
The tracking number and tracking link land on the lead.
Samples sent fills in — but only when Australia Post actually scans the parcel, not when you press the button.
Belinda's email goes, if this was one of those.

What you do next

Nothing. Go back to the list and open the next one. If a request you have already sent still shows in the list, say so — that is worth knowing about.

5 · The rest of Pipedrive

Back to the top

At the bottom of the request there is an Update Pipedrive box. It is for the things dispatching does not already do for you.

  • 1

    Lead stage

    All five stages, set from here. You will not normally need it — dispatching moves the lead to Following up by itself — but if you have spoken to someone and it should say Working or Qualified, set it here rather than going looking for the lead.

  • 2

    Referred them to a stonemason

    Type who you sent them to and press Record it. It goes into the lead history with today's date, so the next person can see the referral happened and to whom. It does not link the company. If that fabricator is already an organisation in Pipedrive and should be linked to this lead, that is still a job in Pipedrive — the page will not guess which one you meant, because guessing is how the CRM ended up with a pile of duplicate companies.

  • 3

    Add a note

    Free text onto the lead. “Called her, wants it next week”. Notes only ever get added, never replaced, so you cannot wipe out something that was already there.

Each one has its own button and tells you what it did. If it says something went wrong, nothing was written — try again, and if it fails twice, message Sean.

When something looks wrong

Back to the top

Four things you might see, and what each one means.

  • 1

    “This one cannot be sent yet”

    Something is missing from the address — no street, no postcode, no suburb. The box lists exactly what. Fix it on the person in Pipedrive, reload, and the message goes away. The Dispatch button stays switched off until it does, so you cannot accidentally post a box into nowhere.

  • 2

    “Already sent” with a tracking number

    This one has gone out. Nothing to do — and pressing anything will not send a second box.

  • 3

    “Could not reach the server”

    Reload the page. If it says it twice, stop and message Sean. Do not fall back to typing the address into MyPost Business by hand to get it out the door, because then nobody can tell which parcels the system sent and which it did not.

  • 4

    It is not a real request

    A test, a duplicate, or somebody who clearly is not after samples. Use Close this request at the bottom. It asks you to confirm, and then the request stops appearing in the list.

If the page and the screen disagree, the page is wrong.

These notes were written before you used it in anger. If something does not match what is in front of you, send Sean a screenshot — that is faster than working around it, and it stops the next person hitting the same thing.
